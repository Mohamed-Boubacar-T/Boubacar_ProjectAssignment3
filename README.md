# Boubacar_ProjectAssignment3

ESCI 620 Week 5: Kerala dissolved oxygen regression.

## Reproduce
Use Python 3.13 (tested with 3.13.5). Install dependencies with `python -m pip install -r requirements.txt`. Open the notebook in Jupyter from this folder and run all cells. The raw CSV must be beside the notebook. The notebook recreates the modeling CSV, validation metrics, predictions and figures.

## Submission
The notebook includes executed outputs, interpretation and references. The cleaned modeling CSV retains all source records and marks train/test/excluded rows. This is a modeling-specific subset, not the full Week 3 cleaned file.

The repository, notebook and cleaned modeling dataset use the required name `Boubacar_ProjectAssignment3`. The notebook exports `Boubacar_ProjectAssignment3.csv` when rerun.
